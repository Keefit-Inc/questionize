# Argument Judge evaluation

The Argument Judge (docs/ARCHITECTURE.md §4.5) is only as trustworthy as its calibration. This folder holds the gold set it is scored against.

## Gold set format

`gold.jsonl`, one item per line (see `gold.example.jsonl`):

| Field | Meaning |
|---|---|
| `id` | Stable identifier |
| `passage`, `stem`, `choices` | The argument, question and five options A–E, in our own words |
| `subtype` | `weaken`, `strengthen` or `assumption` (the sub-types the judge gates today) |
| `gold_label` | The answer a human adjudicator settled on |
| `adjudicator`, `notes` | Who decided and why, including which trap each strong distractor sets |

Only original items go in the gold set: our own writing or items generated by Questionize and then adjudicated by a person. Never copy items from published test-prep material.

## Running

```bash
cd ai
python -m questionize.eval_judge eval/gold.jsonl --out eval/report.json
```

This calls the configured judge models (it needs a provider key in `ai/.env`) and prints accuracy, the gate pass rate, the mean margin and the expected calibration error. Results are published per judge version.
