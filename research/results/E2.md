# E2 v2 — Matched CR design-procedure scaffold

The candidate did not improve first-draft verification. **Hold it; retain the current production writer.** This is a procedure-scaffold comparison, not the still-unexecuted v1 study of memory sizes learned from official items.

Twenty matched tasks covered strengthen, weaken, assumption, inference and explain, each on four original topic briefs. Both conditions received the same objective, trap, difficulty and topic, without an official question or explanation. The candidate added our attributed abstract design procedures; each condition had one drafting call and the same zero-revision verification pipeline. Model: Meta `muse-spark-1.3`, provider-default reasoning effort (not explicitly pinned), fixed paired order alternation. Blind solving, Critic and applicable Argument Judge are AI proxies from the same model family.

Run: `20261030T225620Z-e2-2994f9`. All 40 drafts completed, zero execution errors, 233 logical calls total, 1,508 seconds wall time.

| Condition | First draft passed | Wilson 95% interval | Calls |
|---|---|---|---|
| Current writer | 18/20 (90%) | 69.90%–97.21% | 119 |
| Candidate procedures | 18/20 (90%) | 69.90%–97.21% | 114 |

One baseline-failing pair passed with the candidate; one baseline-passing pair failed with it. The registered no-regression and positive-gain release gate therefore fails. A longer or more explicit writing procedure alone is not evidence of better questions. Rejected drafts are retained privately; none of these research items was imported into a learner account or the shared Bank.

The local secondary check compared all 40 draft passages with the 124 private source passages: no shared run exceeded twelve words (maximum four). Returned subtype metadata matched all 40 requested tasks. These check literal overlap and a metadata contract, not semantic originality or quality. A blinded pairwise rating sheet is available locally and remains unrated. Human key uniqueness, precise objective/trap adherence, difficulty and learner benefit remain unmeasured.

Related primary references and the distinction between method references and answer-key evidence are recorded in [RESEARCH_REFERENCES.md](../../docs/RESEARCH_REFERENCES.md). This experiment does not reproduce predictive example retrieval, train model weights or demonstrate a benefit from OG design memory.
