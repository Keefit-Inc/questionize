# Subjects

One folder per subject pack, named by its subject id (the `subject` field in the ledger). A pack defines what the six capabilities need to know about a subject; it does not hold items or item text (see the data policy).

| Subject id | Pack | Status |
|---|---|---|
| `CR` | [Critical Reasoning](CR.md) | Active |
| `RC` | Reading Comprehension | Active in the app; no experiments yet |
| `math-*`, `physics-*` | | Later |

A pack states:

1. **Skills and objectives**: the sub-types and competencies questions assess, with the standards they map to.
2. **Question parts**: what a question in this subject can contain (passage, stem, options; figures, tables, graphs, formulas, units, code) and how each is reconstructed for C1.2 (for example a geometry figure as given measures and relations).
3. **Traps and misconceptions**: the subject's catalogue, used by C2 and C4.
4. **Levels**: which skills are in scope at each level.
5. **Datasets**: private dataset ids with their source kinds and counts.
6. **Bars**: any measure or bar that differs from the capability default, with the reason.
